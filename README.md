# pq_call_analysis
Code used for the analysis of poor quality calls to improve ECG quality in the [SAFER Research Programme](https://www.safer.phpc.cam.ac.uk/), as used in:

Kethaki Prathivadi Bhayankaram et al., 'Telephone training to improve ECG quality in remote screening for atrial fibrillation', _Physiological Measurement_, **45** 125005, 2024, https://doi.org/10.1088/1361-6579/ad9798
